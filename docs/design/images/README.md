# Placeholder images

These are **dev placeholders**, generated with AI, so Claude Design and the agents can design with real-looking photos. Every one is replaced with a real photo before launch (Phase 7). Never ship an AI-generated face as Ahmed or as someone he worked with.

## What to do

1. Generate each image below with your image tool. Copy the prompt as it is; it already includes the style.
2. Save it **in this folder** (`docs/design/images/`) with the exact file name, as JPG, at least the size given.
3. Attach the ones you have to Claude Design when you start (see `../claude-design-prompt.md`).
4. Tell the lead (or me) when they're in. The Phase 8 Foundation task takes it from there:
   - Images marked **content** are uploaded to the dev project through the dashboard (they are content the team will replace there later: the hero photo, project galleries).
   - Images marked **design** are optimized into `apps/web/public/images/` and used by the layout itself.

If an image comes out with readable text, logos, flags, extra fingers or a staged look, regenerate it. Don't fix it in code.
